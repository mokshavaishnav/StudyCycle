# 🎯 StudyCycle – Smart Study & Productivity App

StudyCycle is a productivity web application designed to help students improve focus, manage study time, and refresh their minds through fun mini-games.

## ✨ Features

### ⏱️ Pomodoro Timer
- Start, pause, and reset study sessions.
- Manage focused study and break intervals.
- Improve productivity and time management.

### 🎮 Mind Refresh Zone
- Play mini-games during study breaks.
- Take a mental break from continuous studying.
- Refresh your mind before starting the next session.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
